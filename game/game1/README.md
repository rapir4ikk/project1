# game1 — версия с enum class и отдельными классами

В проекте сохранены классы NPC, Evil, Warrior, Wizard, Paladin и Player. Классы воин, маг и паладин вынесены в отдельные заголовочные и исходные файлы. В `Source.cpp` используются два перечисления `enum class`: `CharacterType` для выбора персонажа и `WeaponQuality` для качества оружия.

Откройте `game1.slnx` или `game1.vcxproj` в Visual Studio и запустите проект. GitHub в момент подготовки архива не удалось открыть, поэтому сборка основана на ранее загруженном `game1.zip` и сохранённой версии проекта.
