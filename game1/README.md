# game1

Учебный C++ проект с ООП и наследованием.

## Структура исходников

- `NPC.h/.cpp` — базовый класс персонажа и получение урона.
- `Warrior.h/.cpp` — воин.
- `Wizard.h/.cpp` — маг.
- `Evil.h/.cpp` — противник.
- `Paladin.h/.cpp` — паладин (множественное наследование).
- `Player.h/.cpp` — хранение выбранного персонажа.
- `Weapon.h`, `Spell.h` — структуры оружия и заклинания.
- `Source.cpp` — точка входа `main`.

Откройте `game1.slnx` в Visual Studio. Артефакты сборки (`x64`, `.obj`, `.pdb`, `.tlog`) не являются исходниками и не нужны для компиляции.
